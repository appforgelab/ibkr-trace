# Phase 05: FX

## Intent

Import daily FX rates for later GBP-enriched reporting.

## Implementation Decisions

- accept local CSV input only
- normalize to one row per rate date and currency pair
- keep FX support independent from the trace engine

## Interfaces Touched

- `uv run ibkr-trace import fx --path <file>`

## Acceptance Tests

- same FX file imported twice does not duplicate rows
- duplicate rate dates do not create multiple rows for the same pair

## PR Checklist

- FX importer implemented
- rate normalization implemented
- tests added
